# Messy Python Code — Student Marks Analysis

## Overview

This project is a Python program that processes student marks across three subjects and generates a report containing each student's total marks, average score, and grade. It also calculates the class average, counts students scoring above the class average, and identifies the topper.

## Features

- **Total Marks:** Calculates the sum of marks obtained by each student across three subjects.
- **Average Score:** Calculates each student's average marks.
- **Grade Assignment:** Assigns grades based on the student's average score.
- **Class Average:** Calculates the average score of all students.
- **Above-Average Count:** Counts students whose average is greater than the class average.
- **Topper Identification:** Identifies the student with the highest average score.
- **Console Report:** Displays the results in the terminal.

## Technologies Used

- Python 3
- Basic Python concepts:
  - Variables and lists
  - Functions
  - Loops
  - Conditional statements
  - Arithmetic operations
  - String formatting

## Student Dataset

The program uses sample marks for five students:

| Student | Subject 1 | Subject 2 | Subject 3 |
|---|---:|---:|---:|
| Rahul | 78 | 88 | 92 |
| Priya | 65 | 71 | 69 |
| Amit | 90 | 94 | 85 |
| Sneha | 55 | 60 | 58 |
| Vikram | 82 | 79 | 88 |

## Grading Criteria

The program assigns grades according to the following average-score thresholds:

| Average Score | Grade |
|---|---|
| 90 or above | A |
| 80–89.99 | B |
| 70–79.99 | C |
| 60–69.99 | D |
| Below 60 | F |

## How to Run

### Prerequisites

Install Python 3 on your computer. No external libraries are required.

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/HARSH1-rgb/Messy-Python_code-25BCON1092.git
   ```

2. Open the project directory:

   ```bash
   cd Messy-Python_code-25BCON1092
   ```

3. Run the Python script:

   ```bash
   python "messy.py"
   ```

The program will print the student report, class average, number of above-average students, and topper information in the terminal.
